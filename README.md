# 🎬 AI Video Pipeline Demo (ETL for Media)

Автоматизированный пайплайн генерации вертикальных видеороликов (формат Reels/Shorts 9:16) из текстового описания. Проект демонстрирует подход **ETL (Extract, Transform, Load)** применительно к медиа-контенту: от идеи до готового видео с автоматизированным рендером.

## 🚀 Возможности
- **Генерация визуала**: Автоматический запрос к API генерации изображений (в демо используется Pollinations.ai, в продакшене легко заменяется на Midjourney/Runway API).
- **Генерация аудио**: Синтез речи из текста (gTTS, масштабируется до ElevenLabs).
- **Автоматический монтаж**: Сборка видео через `FFmpeg` с применением фильтров:
  - Приведение к целевому разрешению 1080x1920 (вертикальный формат).
  - Эффект плавного приближения (Ken Burns effect / `zoompan`).
  - Синхронизация длительности видео с аудиодорожкой.
- **Надежность**: Структурированное логирование (`logging`), обработка таймаутов и проверок окружения.

## 🏗️ Архитектура пайплайна
1. **Extract**: Чтение текстового промпта и сценария из конфигурации.
2. **Transform**: 
   - HTTP-запрос к генеративной модели для получения изображения.
   - Запрос к TTS-сервису для генерации аудиофайла и считывание его метаданных (длительность).
3. **Load**: Выполнение FFmpeg-команды для кодирования (`libx264` + `aac`) и финальной сборки MP4-файла.

## 🛠️ Стек технологий
- **Язык**: Python 3.12
- **Мультимедиа**: FFmpeg (кодирование, фильтрация, монтаж)
- **Библиотеки**: `requests`, `gTTS`, `mutagen`, `subprocess`, `logging`

## ⚙️ Установка и запуск
1. Убедитесь, что в системе установлен FFmpeg: `sudo apt install ffmpeg -y`
2. Установите зависимости: `pip install requests gTTS mutagen`
3. Запустите пайплайн: `python video_pipeline.py`
4. Готовое видео будет сохранено в директории `./output/final_reel.mp4`.

## 📈 Production Readiness & Масштабирование
Данный код является MVP. Для промышленного использования (контент-фабрика) пайплайн легко масштабируется:
- **Очереди задач**: Интеграция с Celery + Redis для асинхронной обработки и ретраев при Rate Limit API.
- **Управление стоимостью (Cost Optimization)**: Маршрутизация запросов: черновики генерируются через дешевые/open-source модели, финальный рендер — через премиальные API.
- **Контроль качества (Video Quality)**: Добавление пре- и пост-валидации (проверка битрейта, разрешения, отсутствие тишины в аудио).
- **Контейнеризация**: Упаковка пайплайна в Docker-образ для гарантированного воспроизведения окружения.
